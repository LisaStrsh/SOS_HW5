# ДЗ №5 — Online Cinema

Реализован pipeline обработки событий онлайн-кинотеатра:

`Movie Service → Kafka → ClickHouse → Aggregation Service → PostgreSQL → S3`

## Что сделано

- Описана Avro-схема событий v1 и настроена её автоматическая регистрация в Schema Registry.
- Поднят кластер из трёх брокеров Kafka. Топик `movie-events` содержит 3 партиции, replication factor — 2, `min.insync.replicas=1`.
- Реализован HTTP-продюсер с валидацией, подтверждением доставки, повторными попытками и логированием. Генератор создаёт последовательности просмотров, пауз, продолжений, лайков и поиска.
- Настроен приём событий в ClickHouse через Kafka Engine и Materialized View. Raw-события хранятся в ReplacingMergeTree с партиционированием по месяцу и сортировкой по дате и `event_id` для дневных запросов и дедупликации.
- Отдельный сервис рассчитывает DAU, средний прогресс завершённых просмотров, топ фильмов, конверсию и retention D1/D7. Агрегаты материализуются в ClickHouse и сохраняются в PostgreSQL без дублирования при повторном пересчёте.
- В Grafana настроены ClickHouse datasource и дашборд: когортная тепловая карта Day 0–7, DAU, конверсия, среднее время просмотра и топ фильмов.
- Настроен автоматический экспорт агрегатов из PostgreSQL в S3-совместимое хранилище SILO (форк MinIO). JSON-файлы сохраняются по пути `s3://movie-analytics/daily/YYYY-MM-DD/aggregates.json`; повторный экспорт перезаписывает файл.
- Миграции и настройка инфраструктуры выполняются автоматически. Для сервисов предусмотрены health checks.

Ключ партиционирования Kafka — **user_id**, чтобы сохранять порядок событий одного пользователя.

Метрики рассчитываются по дням UTC. Когорта определяется датой первого `VIEW_STARTED`, возврат — событием просмотра в соответствующий день. Незавершённые дни retention остаются пустыми. По умолчанию пересчёт выполняется каждые 60 секунд; интервал задаётся через `AGGREGATION_INTERVAL_SECONDS`.

## Запуск

Нужны Docker и Docker Compose.

```bash
docker compose up -d --build
```

Все компоненты также запускаются командой `docker-compose up`. Генератор автоматически наполняет систему демонстрационными данными.

| Интерфейс | Адрес | Логин / пароль |
|---|---|---|
| API событий | http://localhost:8000/docs | — |
| API агрегации и экспорта | http://localhost:8001/docs | — |
| Grafana | http://localhost:3000/d/movie-analytics | `admin` / `cinema-admin` |
| S3 Console | http://localhost:9001 | `minioadmin` / `cinema-minio-admin-2026` |

Все указанные пароли — демонстрационные значения для локальных контейнеров этого задания; опубликованные порты доступны только через localhost.

Ручной пересчёт и экспорт за выбранную дату:

```bash
curl -X POST 'http://localhost:8001/aggregate?date=2026-11-24'
curl -X POST 'http://localhost:8001/export?date=2026-11-24'
```

## Проверка

```bash
./scripts/test.sh
```

Тесты проверяют доставку события через продюсер в ClickHouse, корректность метрик, повторный пересчёт, экспорт в S3 и запросы Grafana. Данные тестов изолированы, поэтому проверки можно запускать многократно.

Проверка работы при остановке одного брокера:

```bash
./scripts/test-failover.sh
```

Оба набора проверок выполнены успешно: по 16 тестов. Подробные результаты — в `TEST_RESULTS.txt`.
